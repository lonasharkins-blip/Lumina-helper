# Regras do projeto

1. O código deste repositório é a fonte principal da verdade.
2. Alterações devem preservar tudo que já funciona e ficar limitadas ao pedido confirmado.
3. O projeto deve ser original. Não copiar código, interface, marca, músicas ou arquivos de outros aplicativos.
4. Toda automação de toque precisa de ativação e controle explícitos do usuário.
5. Perfis de instrumentos não podem depender de uma quantidade fixa de teclas.
6. Instrumentos pequenos, como o piano de emoji do JJS, e layouts de 15 ou 21 teclas devem usar a mesma estrutura configurável.
7. Novas regras de conversão de notas precisam de testes unitários.
8. `PROJECT_STATUS.md` deve ser atualizado junto com mudanças relevantes.
9. Não armazenar chaves, senhas ou dados pessoais no repositório.
